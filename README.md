# 📱 Mobile Sales Dashboard | Power BI

## 📌 Overview

An interactive **Mobile Sales Dashboard built using Microsoft Power BI** to analyze mobile sales performance, units sold, transactions, average price, brands, mobile models, cities, payment methods, customer ratings, and sales trends.

The dashboard includes multiple views for overall sales analysis, Month-to-Date (MTD) performance, and Same Period Last Year comparison.

## 🎯 Objective

- Analyze overall mobile sales performance
- Track total sales, quantity, and transactions
- Analyze average price
- Compare sales across brands and mobile models
- Identify high-performing cities
- Analyze payment methods
- Understand customer rating distribution
- Analyze monthly and daily sales trends
- Compare current performance with the same period last year
- Monitor Month-to-Date sales performance

## 📂 Dataset

The project uses the `Mobile Sales Data.xlsx` dataset containing mobile sales transaction data.

The dataset includes information related to:

- Transaction ID
- Date
- Brand
- Units Sold
- Price Per Unit
- Customer Name
- Customer Age
- City
- Payment Method
- Customer Ratings
- Mobile Model

A calculated sales measure is derived using:

**Sales = Units Sold × Price Per Unit**

## 🔍 Key Insights

- The dashboard reports approximately **₹769.20M in total sales** across **19.15K units**.
- The dataset contains approximately **3.84K transactions**.
- The average price per unit is approximately **₹40.11K**.
- **Apple** has the highest displayed total sales among the brands shown.
- **iPhone SE** is the highest-performing mobile model by displayed sales.
- **Delhi** records the highest displayed sales among the cities shown.
- **UPI** is the most-used payment method, accounting for approximately **26.36%** of transactions.
- **July** records the highest displayed monthly quantity.
- Customer ratings are categorized into **Good, Average, and Poor** for analysis.
- The dashboard includes **MTD** and **Same Period Last Year** analysis for time-based performance comparison.
